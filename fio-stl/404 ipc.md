# IPC — Inter-Process Communication (404 ipc.h)

```c
#define FIO_IPC
#include FIO_INCLUDE_FILE
```

IPC is the messaging backbone of the facil.io worker/master model. Workers fork from a master process. The master keeps listeners, manages state, and handles anything that needs a single authoritative view of the world. Workers handle client connections. IPC bridges the two: a worker sends a message to the master (or to every process in the cluster), the master executes it and optionally streams replies back.

IPC supports local messages and, when configured with a shared secret, messages between cluster peers. Register op-codes for messages sent between machines; do not send function pointers across machines.

See [./400 io-overview.md](./400 io-overview.md) for where IPC sits in the full IO stack.

---

## Worker/Master Model

Workers send local messages through the master. Use `fio_ipc_call` to reach the master, or `fio_ipc_local` to reach the master and local workers. For cluster peers, use `fio_ipc_cluster` or `fio_ipc_broadcast`.

## Types

### `fio_ipc_s` — the message

```c
typedef struct fio_ipc_s {
  fio_io_s *from; /* originating IO on receipt */
  uint32_t len;   /* payload length */
  uint16_t flags; /* application flags */
  uint16_t routing_flags; /* routing state; do not edit directly */
  uint64_t timestamp; /* message timestamp */
  uint64_t id;        /* message ID (deduplication / replay filter) */
  uint64_t nonce;     /* fresh random value per encryption */
  union {
    void (*call)(struct fio_ipc_s *); /* local handler */
    uint32_t opcode;                  /* registered handler ID */
  };
  void (*on_reply)(struct fio_ipc_s *); /* reply handler */
  void (*on_done)(struct fio_ipc_s *);  /* final reply handler */
  void *udata; /* caller context */
  char data[]; /* payload; read only len bytes */
} fio_ipc_s;
```

Messages are reference-counted. In callbacks, `data` contains `len` payload bytes; do not assume it is null-terminated. Treat routing state as read-only.

### `fio_ipc_args_s` — construction arguments

```c
typedef struct {
  void (*call)(fio_ipc_s *);     /* function to run on target (required for local IPC) */
  void (*on_reply)(fio_ipc_s *); /* called on caller when a reply arrives */
  void (*on_done)(fio_ipc_s *);  /* called on caller when final reply arrives */
  fio_io_s *exclude;             /* IO to exclude from delivery (or FIO_IPC_EXCLUDE_SELF) */
  uint64_t timestamp;            /* force timestamp; 0 = wall-clock ms (cached) */
  uint64_t id;                   /* force message ID; 0 = random (see below) */
  uint32_t opcode;               /* registered op-code; replaces call if non-zero */
  uint16_t flags;                /* user-settable flags */
  bool cluster;                  /* deliver to remote machines in cluster */
  bool workers;                  /* deliver to master + all local workers */
  void *udata;                   /* opaque pointer for reply callbacks */
  fio_buf_info_s *data;          /* payload (use FIO_IPC_DATA macro) */
} fio_ipc_args_s;
```

### `fio_ipc_opcode_s` — op-code registration

```c
typedef struct fio_ipc_opcode_s {
  uint32_t opcode;                      /* unique non-zero value */
  void (*call)(struct fio_ipc_s *);     /* handler */
  void (*on_reply)(struct fio_ipc_s *); /* reply callback */
  void (*on_done)(struct fio_ipc_s *);  /* final reply callback */
  void *udata;                          /* provided to handler via ipc->udata */
} fio_ipc_opcode_s;
```

### `fio_ipc_reply_args_s` — reply arguments

```c
typedef struct {
  fio_ipc_s *ipc;       /* original request (required) */
  fio_buf_info_s *data; /* reply payload */
  uint64_t timestamp;   /* 0 = wall-clock ms (cached) */
  uint64_t id;          /* 0 = fresh random ID */
  uint16_t flags;       /* 0 = use original request flags */
  uint8_t done;         /* set to 1 on last reply (triggers on_done on caller) */
  uint8_t flags_set;    /* set to 1 to allow flags=0 override */
} fio_ipc_reply_args_s;
```

## Helper Macro: `FIO_IPC_DATA`

```c
#define FIO_IPC_DATA(...)  \
  (fio_buf_info_s[]){ __VA_ARGS__, { .len = ((size_t)-1) } }
```

Composes multiple buffers into a single message without intermediate allocation. Iteration stops at the first entry with `len == (size_t)-1` (the terminator the macro appends). Zero-length elements are allowed and skipped; an element with a `NULL` `buf` and a non-zero `len` contributes that many zero bytes. A combined length that overflows `size_t` fails the message.

```c
uint32_t seq = 42;
const char *text = "hello";

fio_ipc_call(.call = my_handler,
             .data = FIO_IPC_DATA(
                 FIO_BUF_INFO2(&seq, sizeof(seq)),
                 FIO_BUF_INFO1((char *)text)));
/* seq and text are copied immediately — stack safe */
```

## Delivery Macros

All four macros call `fio_ipc_new(...)` then `fio_ipc_send(...)`. They accept named fields from `fio_ipc_args_s`.

| Macro | Delivered to |
|-------|-------------|
| `fio_ipc_call(...)` | master only |
| `fio_ipc_local(...)` | master + all local workers |
| `fio_ipc_cluster(...)` | master process on every machine (local and remote) |
| `fio_ipc_broadcast(...)` | master + workers on every machine (local and remote) |

```c
/* worker → master */
#define fio_ipc_call(...)      fio_ipc_send(fio_ipc_new(__VA_ARGS__))
/* all local processes */
#define fio_ipc_local(...)     fio_ipc_send(fio_ipc_new(.workers = 1, __VA_ARGS__))
/* remote masters only */
#define fio_ipc_cluster(...)   fio_ipc_send(fio_ipc_new(.cluster = 1, __VA_ARGS__))
/* everywhere */
#define fio_ipc_broadcast(...) fio_ipc_send(fio_ipc_new(.workers = 1, .cluster = 1, __VA_ARGS__))
```

`fio_ipc_cluster` and `fio_ipc_broadcast` require an `opcode` (not a function pointer) because function pointers are meaningless across machine boundaries.

Use `.exclude = FIO_IPC_EXCLUDE_SELF` to skip the calling process when broadcasting locally.

**`FIO_IPC_EXCLUDE_SELF`**

```c
#define FIO_IPC_EXCLUDE_SELF ((fio_io_s *)((char *)-1LL))
```

Pass as `.exclude` in `fio_ipc_args_s`, or set `ipc->from = FIO_IPC_EXCLUDE_SELF` before calling `fio_ipc_send`.

## Quick Examples

### Worker calls master, master replies

```c
/* runs on master */
void on_master(fio_ipc_s *msg) {
  printf("master got: %.*s\n", (int)msg->len, msg->data);
  fio_ipc_reply(msg,
                .data = FIO_IPC_DATA(FIO_BUF_INFO1((char *)"pong")),
                .done = 1);
}

/* runs on calling worker when reply arrives */
void on_reply(fio_ipc_s *msg) {
  printf("worker got reply: %.*s\n", (int)msg->len, msg->data);
}

/* somewhere in a worker callback */
fio_ipc_call(.call    = on_master,
             .on_done = on_reply,
             .data    = FIO_IPC_DATA(FIO_BUF_INFO1((char *)"ping")));
```

### Local broadcast (skip self)

```c
void on_notify(fio_ipc_s *msg) {
  printf("[%d] notified: %.*s\n", fio_io_pid(), (int)msg->len, msg->data);
}

fio_ipc_local(.call    = on_notify,
              .exclude = FIO_IPC_EXCLUDE_SELF,
              .data    = FIO_IPC_DATA(FIO_BUF_INFO1((char *)"config-reload")));
```

### Cluster-wide op-code broadcast

```c
#define OP_CACHE_BUST 1

void on_cache_bust(fio_ipc_s *msg) {
  cache_invalidate(msg->data, msg->len);
}

/* register before fio_io_start */
fio_ipc_opcode_register(.opcode = OP_CACHE_BUST, .call = on_cache_bust);
fio_ipc_cluster_listen(9000); /* requires SECRET env var */
fio_io_start(4);

/* later, from any process */
fio_ipc_broadcast(.opcode = OP_CACHE_BUST,
                  .data   = FIO_IPC_DATA(FIO_BUF_INFO1((char *)"key123")));
```

## Reply: `fio_ipc_reply`

```c
SFUNC void fio_ipc_reply(fio_ipc_reply_args_s args);
/* shadowing macro — first arg is the original request */
#define fio_ipc_reply(r, ...) \
  fio_ipc_reply((fio_ipc_reply_args_s){ .ipc = (r), __VA_ARGS__ })
```

Send one or more replies from the master back to the caller. Set `.done = 1` on the final reply to trigger the caller's `on_done` callback. Replies inherit `call`, `on_reply`, `on_done`, and `udata` from the original request. Each reply gets a fresh random `id` unless `.id` is set (it does not reuse the request's `id`).

Streaming replies:

```c
void stream_handler(fio_ipc_s *msg) {
  for (int i = 0; i < 5; ++i) {
    char chunk[32];
    int n = snprintf(chunk, sizeof(chunk), "chunk%d", i);
    fio_ipc_reply(msg,
                  .data = FIO_IPC_DATA(FIO_BUF_INFO2(chunk, (size_t)n)),
                  .done = (i == 4));
  }
}
```

## Op-Code Registration

Op-codes select handlers for cluster messages. Register them before `fio_io_start` on every participating process.

```c
SFUNC int fio_ipc_opcode_register(fio_ipc_opcode_s opcode);
/* named-arg macro */
#define fio_ipc_opcode_register(...) \
  fio_ipc_opcode_register((fio_ipc_opcode_s){ __VA_ARGS__ })

/** Returns registered op-code or NULL. */
SFUNC const fio_ipc_opcode_s *fio_ipc_opcode(uint32_t opcode);
```

- Op-codes must be non-zero `uint32_t` values.
- Values `>= 0xFF000000` are reserved; choose a lower value.
- Pass `call = NULL` to unregister.
- Must be called before `fio_io_start()` (not thread-safe after that).
- Returns 0 on success, -1 on error.

```c
fio_ipc_opcode_register(.opcode = OP_SYNC, .call = on_sync, .udata = ctx);

/* look up */
const fio_ipc_opcode_s *op = fio_ipc_opcode(OP_SYNC);

/* remove */
fio_ipc_opcode_register(.opcode = OP_SYNC, .call = NULL);
```

## IPC URL

The IPC URL is generated at startup. The master can override it before `fio_io_start`:

```c
/** Returns current IPC socket URL. */
SFUNC const char *fio_ipc_url(void);

/**
 * Sets IPC socket URL. Master only, before IO reactor starts.
 * Pass NULL to regenerate. 'X' / '#' characters in the URL are replaced with
 * random hex digits. Returns 0 on success, -1 on error.
 */
SFUNC int fio_ipc_url_set(const char *url);
```

```c
fio_ipc_url_set("unix:///var/run/myapp-XXXX.sock"); /* X replaced randomly */
fio_ipc_url_set(NULL);  /* auto-generate */
printf("%s\n", fio_ipc_url());
```

### Cluster Peer Connection Callbacks

#### `FIO_IPC_CLUSTER_PEER_MAX_SUBSCRIBERS`

```c
#define FIO_IPC_CLUSTER_PEER_MAX_SUBSCRIBERS 32
```

At most 32 peer lifecycle callbacks can be registered per process. Further registrations return `-1`.

#### `fio_ipc_cluster_on_peer_s` and `fio_ipc_cluster_on_peer`

```c
typedef struct fio_ipc_cluster_on_peer_s {
  void (*on_attached)(fio_ipc_s *event); /* optional */
  void (*on_detached)(fio_ipc_s *event); /* optional */
  void *udata; /* callback context; borrowed */
} fio_ipc_cluster_on_peer_s;

SFUNC int fio_ipc_cluster_on_peer(fio_ipc_cluster_on_peer_s args);
#define fio_ipc_cluster_on_peer(...)                                           \
  fio_ipc_cluster_on_peer((fio_ipc_cluster_on_peer_s){__VA_ARGS__})
```

Call on the master before `fio_io_start`. Each call adds a subscriber; at least one callback is required. `udata` may be NULL and remains caller-owned. Keep it valid while callbacks can run. Returns `0` on success, or `-1` for invalid callbacks, a worker, running IO, or full capacity. Registration is not thread-safe. There is no unsubscribe API.

Callbacks borrow a `fio_ipc_s` event whose `data` contains the peer UUID (`event->len == 16`). During `on_attached`, `event->from` identifies the connected peer. During `on_detached`, it is `NULL`. To retain an event beyond the callback, use `fio_ipc_dup` and later `fio_ipc_free`.

**Note:** To send to an attached peer, create a new opcode message and pass it with `event->from` to `fio_ipc_send_to` during the callback. The send takes ownership of the new message. Do not send or reply to the event itself. Keeping an attached event beyond the callback may delay its detach notification.

```c
#define PEER_HELLO_OP 42
static void peer_hello(fio_ipc_s *message) { (void)message; }
static void peer_attached(fio_ipc_s *event) {
  fio_ipc_s *message = fio_ipc_new(
      .cluster = 1, .opcode = PEER_HELLO_OP,
      .data = FIO_IPC_DATA(FIO_BUF_INFO1((char *)"hello")));
  if (message)
    fio_ipc_send_to(event->from, message);
}
static void peer_detached(fio_ipc_s *event) { (void)event; }
/* On each peer before fio_io_start (illustrative setup statements): */
if (fio_ipc_opcode_register(.opcode = PEER_HELLO_OP, .call = peer_hello) ||
    fio_ipc_cluster_on_peer(.on_attached = peer_attached,
                            .on_detached = peer_detached)) {
  /* handle registration failure before starting IO */
}
```

- Call `fio_ipc_cluster_listen` from the master before or after `fio_io_start` to accept and discover peers.
- Set the same `SECRET` environment variable on all instances. Cluster encryption does not provide forward secrecy; rotate the secret by restarting instances.
- All instances receive all `cluster` / `broadcast` messages.
- `fio_ipc_cluster_connect` lets you manually reach peers on other subnets where UDP broadcast doesn't reach.

```c
/* Typical setup */
fio_ipc_opcode_register(.opcode = OP_SYNC, .call = on_sync);
fio_ipc_cluster_listen(9000); /* returns NULL/no-op if SECRET is unset or random */
fio_io_start(4);
```

## Core Lifetime API

Use these functions to construct, send, and retain messages when the delivery macros do not fit your use case.

```c
/** Create a message without sending it. */
SFUNC fio_ipc_s *fio_ipc_new(fio_ipc_args_s args);
#define fio_ipc_new(...) fio_ipc_new((fio_ipc_args_s){ __VA_ARGS__ })

/** Send the message according to its delivery options. Takes ownership. */
SFUNC void fio_ipc_send(fio_ipc_s *ipc);

/** Send directly to a specific IO. Takes ownership. */
SFUNC void fio_ipc_send_to(fio_io_s *to, fio_ipc_s *ipc);

/** Increment reference count. */
SFUNC fio_ipc_s *fio_ipc_dup(fio_ipc_s *msg);

/** Decrement reference count; destroy when zero. */
SFUNC void fio_ipc_free(fio_ipc_s *msg);

/** Release the msg->from IO reference (call if storing msg beyond callback). */
SFUNC void fio_ipc_detach(fio_ipc_s *msg);

/** Set a one-shot callback invoked when sending is complete.
    The callback receives ownership of the decrypted message and must free it.
    Usually runs from an IO thread task; if that task cannot be queued (no
    memory) it runs on the thread calling fio_ipc_free. Not guaranteed to run
    on the IO thread, nor to run at all if the message is discarded. */
SFUNC void fio_ipc_after_send(fio_ipc_s *ipc,
                               void (*fn)(fio_ipc_s *, void *),
                               void *udata);
```

Typical async pattern:

```c
void my_handler(fio_ipc_s *msg) {
  fio_ipc_s *ref = fio_ipc_dup(msg); /* keep alive past callback return */
  fio_ipc_detach(ref);               /* release the from-IO ref if unneeded */
  do_async_work(ref);                /* stored elsewhere */
}

void async_done(fio_ipc_s *msg) {
  process(msg->data, msg->len);
  fio_ipc_free(msg);
}
```

## Message encryption (advanced)

```c
SFUNC void fio_ipc_encrypt(fio_ipc_s *m);
FIO_IFUNC int fio_ipc_decrypt(fio_ipc_s *m);
```

Sending encrypts messages automatically. `fio_ipc_encrypt` encrypts a message in place; `fio_ipc_decrypt` returns `0` on success or nonzero if authentication fails. A failure is final: the message stays marked as encrypted, its payload is not usable, and calling `fio_ipc_decrypt` again fails again. Most applications should use the delivery functions instead.

Messages use ChaCha20-Poly1305 with a per-message key derived by `fio_risky256_keyed` from `timestamp || id || nonce`; the ChaCha20 nonce is `id || nonce`. The KDF key is a 32-byte window of the 64-byte shared secret, starting at byte `(id & 31) + 1`, so messages fall into 32 key groups. `len`, `flags`, and `routing_flags` are associated data; `timestamp`, `id` and `nonce` are authenticated through the key.

`nonce` is a fresh random value on every encryption, so keys never repeat, even when a forced `timestamp` / `id` pair does. Re-sending one encrypted message to many peers reuses its key, which is safe. Default IDs (messages and replies) are fresh random values; cluster peers drop repeated `timestamp` / `id` pairs as replays.

## Connection authentication

Each side of an IPC connection (worker ↔ master and cluster peers) sends one sealed declaration when the connection opens: its instance UUID and role. A valid MAC proves knowledge of the shared secret. The peer's first message must be a valid declaration, otherwise the connection is closed. Until the peer is authenticated, the connection receives no broadcasts, and incoming frames larger than the connection's read buffer wait (the IO is suspended) rather than being allocated.

* Local: the declaration's (monotonic) timestamp must be within 1 second of the time the connection opened (accept / connect), the UUID must match (workers inherit the master's) and the role must be the opposite one (so a declaration can't be reflected back). The UUID is then discarded.
* Cluster: the declaration also carries a random per-connection challenge and must pass the 30 second window and the replay filter below. Because any client can obtain a node's declaration and replay it to another node, each side answers a valid declaration with a sealed proof that echoes the peer's challenge under its own UUID. The peer is authenticated only when its proof echoes our challenge, which costs cluster connections one round trip. The peer UUID is then registered: our own UUID and UUIDs of connected peers are refused.

Connections that do not declare within about 30 seconds are closed.

Cluster messages are also checked against a 30 second window around the wall clock (`fio_io_last_tick_time`, so cluster hosts need synchronized clocks) and a replay filter of recent `timestamp` / `id` pairs. Duplicates are dropped before decryption; only authentic messages are recorded. The filter only forgets pairs that have left the window. If more than 262,144 pairs are inside the window, the oldest are dropped and messages with timestamps at or below theirs are refused from then on (fail closed).

UDP discovery handles at most 64 datagrams per `on_data` event and logs rejected datagrams at most once a second.

## Routing Flags

The routing flags are defined in the header for advanced use. Prefer the delivery macros and `.flags` for application data. Do not modify `routing_flags` on a received message:

```c
#define FIO_IPC_FLAG_ENCRYPTED  ((uint16_t)1 << 0) /* message is encrypted */
#define FIO_IPC_FLAG_DONE       ((uint16_t)1 << 1) /* final reply */
#define FIO_IPC_FLAG_OPCODE     ((uint16_t)1 << 2) /* route via op-code */
#define FIO_IPC_FLAG_WORKERS    ((uint16_t)1 << 3) /* deliver to workers too */
#define FIO_IPC_FLAG_CLUSTER    ((uint16_t)1 << 4) /* deliver to remote machines */
#define FIO_IPC_FLAG_REPLY      ((uint16_t)1 << 5) /* this is a reply */
#define FIO_IPC_FLAG_PING       ((uint16_t)1 << 6) /* internal keepalive */
#define FIO_IPC_FLAG_HELLO      ((uint16_t)1 << 7) /* internal declaration */

/** Test a flag: returns flag value if set, 0 otherwise. */
#define FIO_IPC_FLAG_TEST(msg, flag) (((msg)->routing_flags & (flag)) == (flag))
```

## Memory Management

- Messages are reference-counted (`fio_ipc_dup` / `fio_ipc_free`).
- Callbacks receive a message pointer valid for the duration of the callback.
  The system frees it automatically after the callback returns.
- Call `fio_ipc_dup` to keep a message alive beyond the callback, then
  `fio_ipc_free` when done.
- Data passed via `FIO_IPC_DATA` is copied into the message immediately —
  source buffers may be stack-allocated or freed right after the call. A
  `NULL` buffer with a nonzero length adds that many zero bytes.

---

## Thread Safety

- `fio_ipc_call`, `fio_ipc_local`, `fio_ipc_cluster`, `fio_ipc_broadcast`,
  and `fio_ipc_reply` are safe to call from any thread.
- `fio_ipc_dup` / `fio_ipc_free` are thread-safe.
- `fio_ipc_opcode_register` is **not** thread-safe after `fio_io_start`.
- `fio_ipc_url_set` must be called on the master before `fio_io_start`.
